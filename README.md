**RESIDEX** is a desktop application for property agents who manage buyers and sellers.

* Keep client contact details, remarks and an ordered list of associated properties together.
* Record each property's type, Buying or Selling intention, location, optional whole-dollar price and transaction status. Prices belong to properties; there is no separate client budget field.
* See each client's role derived from their properties: Buyer, Seller, Buyer / Seller or Not specified.
* Find clients by name, email, phone, property location, derived role or property status.
* Enter `view INDEX` to review one client's full details, then `list` to return to all clients.
* Type commands and press Enter or click **Run**. The interface displays the current list, command feedback and the data-file location.

For usage and development instructions, see the [User Guide](docs/UserGuide.md),
[Developer Guide](docs/DeveloperGuide.md) or [RESIDEX Product Website](https://ay2627s1-cs2103t-w11-4.github.io/tp/).
